NovaPrompt Lab User Guide

Introduction

Welcome to NovaPrompt Lab! This tool helps you craft, test, save, and organize prompts for interacting with local Large Language Models (LLMs) via the LM Studio API. You can also chain prompts together into simple workflows.

Main Interface Overview

The application window is divided into several key areas:

  • Menu Bar (Top): Contains File (Exit) and Help (Guides) menus.
  • Left Panel (Tabs):
    • Prompts Tab: Manage your individual saved prompts. Contains filtering, searching, the prompt list, and a preview area.
    • Workflows Tab: Define and manage sequences of prompts (workflows). Contains workflow list, step list, and controls.
  • Right Area (Split View):
    • Top Section (Editor Area): Where you write and edit your prompts. Includes fields for Category, Notes, Output Variable Name, and the dynamic Prompt Variables section (if using templates).
    • Bottom Section (Output & Controls): Displays the Generated Output from the LLM. Also contains controls for selecting the Model, setting Temperature and Max Tokens, and action buttons like Generate Response and Copy Output to Editor.
  • Workflow Log (Dockable Panel): Appears at the bottom when running workflows, showing step-by-step progress and intermediate outputs. Toggle visibility via the View menu.
  • Status Bar (Bottom): Displays informational messages about application status and actions.

Core Tasks

1. Managing Prompts (Prompts Tab)

  • Saving:** Type your prompt in the Prompt Editor. Optionally fill in Category, Notes, and (for workflows) Output Variable Name. Click Save Prompt. If it's a new prompt, it's added; if you loaded an existing prompt, it's updated.
  • Loading:** Select a prompt in the Saved Prompts list. Click Load Selected. The prompt text, category, notes, and output variable name will load into the editor section.
  • Deleting:** Select a prompt in the Saved Prompts list. Click Delete Selected and confirm.
  • Previewing:** Simply click on a prompt in the Saved Prompts list. Its details (including category, notes, output variable, and full text) will appear in the Preview area below the list.
  • Clearing:** Click New / Clear Editor to clear all editor fields, variable inputs, and the generated output, ready for a new prompt.

2. Finding Prompts (Prompts Tab)

  • By Category:** Use the Filter by Category dropdown to show only prompts matching a specific category or "[Uncategorized]". Select "All Categories" to see everything.
  • By Keyword:** Type keywords into the Search Prompts field. The list will update automatically to show prompts where the keyword appears in the prompt text, category, or notes (case-insensitive).
  • Combined:** Use both the category filter and search field simultaneously for more specific results.

3. Generating a Single Response

  1. Ensure LM Studio is running with the desired model loaded and the API server started.
  2. In NovaPrompt Lab, select the correct loaded model from the Model dropdown. Click Refresh if needed.
  3. Write or load your prompt into the Prompt Editor.
  4. If using a template with {variables}, fill in the values in the Prompt Variables section that appears.
  5. Adjust Temp (Temperature, 0.0-2.0, higher is more creative) and Max Tokens (max response length) as needed.
  6. Click Generate Response.
  7. Output will stream into the Generated Output area. A progress dialog may briefly appear and can be used to cancel.
  8. Use Copy Output to Editor to append the result back to your prompt editor for further refinement.

4. Using Prompt Templates (Variables)

  • Syntax:** Define variables by enclosing a name in curly braces: {variable_name}. Use only letters, numbers, underscores.
  • Input:** When variables are detected in the Prompt Editor, the Prompt Variables section appears below it with input fields for each unique variable.
  • Substitution:** Fill in the values. When you click Generate Response (or run a workflow step), the app replaces the {variable_name} placeholders with the values you provided before sending the final text to the LLM.
  • Example Template:** 
    Explain the concept of {concept} in simple terms suitable for a {audience_level}. Focus on its main application in {context}.
    Variables Detected: {concept}, {audience_level}, {context}

5. Defining Workflows (Workflows Tab)

  1. Go to the Workflows tab.
  2. Click New, enter a name (e.g., "Generate & Summarize Story Idea"), click OK. The new workflow appears selected in the Workflows list.
  3. Go back to the Prompts tab. Find and save prompts intended as steps. **Crucially:** For steps whose output needs to be used later, fill in the Output Variable Name field when saving the prompt (e.g., `story_idea`).
  4. Select the first prompt for your workflow in the Saved Prompts list (e.g., one that generates a story idea and has `story_idea` as its Output Variable Name).
  5. Switch back to the Workflows tab. Ensure your workflow ("Generate & Summarize...") is selected.
  6. Click Add Prompt as Step. The prompt appears in the Workflow Steps list.
  7. Go back to the Prompts tab. Find and select the *next* prompt (e.g., one that contains the variable `{story_idea}` and maybe defines its own output like `story_summary`).
  8. Switch back to the Workflows tab. Click Add Prompt as Step again.
  9. Repeat adding steps as needed.
  10. Use the Up / Down / Remove Step buttons to manage the sequence. Changes are saved automatically.

6. Running Workflows (Workflows Tab)

  1. Select the desired workflow in the Workflows list.
  2. Ensure the correct Model is selected and Parameters are set in the bottom-right panel (these apply to all steps currently).
  3. Click Run Workflow.
  4. If the workflow requires initial inputs (variables used in steps that are *not* provided by a previous step's output variable), a dialog box will appear asking you to enter values. Fill them in and click OK.
  5. The workflow will execute step-by-step. Progress and intermediate outputs appear in the Workflow Log panel (use View -> Workflow Log menu to show/hide it).
  6. The final output from the *last* step appears in the main Generated Output area when the workflow finishes or fails.

Workflow Example Walkthrough

Let's create a 2-step workflow: Generate a topic, then write a tweet about it.

  1. Save Prompts:
    • Save Prompt 1: Text = Generate a single, interesting science topic., Category = WF-Step, Output Variable Name = science_topic
    • Save Prompt 2: Text = Write a short, engaging tweet about {science_topic}. Include one relevant hashtag. Max 250 chars., Category = WF-Step, Output Variable Name = tweet_text
  2. Define Workflow:
    • Go to Workflows tab, click New, name it "Science Tweet".
    • Go to Prompts tab, select Prompt 1.
    • Go to Workflows tab, click Add Prompt as Step.
    • Go to Prompts tab, select Prompt 2.
    • Go to Workflows tab, click Add Prompt as Step.
    • The steps list should show Prompt 1 (outputting `{science_topic}`) then Prompt 2.
  3. Run Workflow:
    • Ensure "Science Tweet" is selected. Select your desired LLM Model.
    • Click Run Workflow.
    • (No initial input dialog should appear, as the first step has no input variables).
    • The Workflow Log will show "Starting Step 1...", then "Step 1 Finished. Output Variable: {science_topic}", then "Starting Step 2...", then "Step 2 Finished. Output Variable: {tweet_text}".
    • The final generated tweet will appear in the main Generated Output area.

Tips & Troubleshooting

  • LM Studio Connection:** Ensure LM Studio is running and the API server is started *before* running NovaPrompt Lab or using the Refresh button. Verify the API URL (usually `http://localhost:1234/v1`).
  • Model Loading:** Models must be fully loaded in LM Studio before they appear in the Model dropdown after clicking Refresh.
  • Concise Output:** The app automatically adds instructions to prompts sent to the AI to minimize conversational filler. If you still get unwanted introductions, try making your core prompt instructions even more direct.
  • Workflow Errors:** If a workflow fails, check the Workflow Log. Common issues include missing initial inputs or mismatches between an `Output Variable Name` in one step and the {variable_name} used in the next. Variable names are case-sensitive!
  • Variable UI:** If the Prompt Variables section doesn't update correctly after pasting text, try adding or deleting a character in the editor to re-trigger the detection.
